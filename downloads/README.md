# Catalogo Albertelli Kitchen 2026

[Scarica il pacchetto ZIP](https://github.com/dimadjdima87/Programmi-arredo/raw/refs/heads/main/downloads/Albertelli-Kitchen-Catalogo-2026.zip)

Nel programma Windows 0.4.0, apri **Albertelli Kitchen → Carica catalogo 2026**,
seleziona il file ZIP senza estrarlo e premi **Conferma caricamento**.
Il catalogo sarà disponibile anche senza connessione.

Il pacchetto è stato pubblicato su istruzione esplicita dello studio il
22 ottobre 2026, per consentirne il download dal repository pubblico.
Il PDF originale non è incluso. L'importazione non abilita ancora il calcolo
automatico dei costi o il posizionamento dei mobili reali in pianta.

Il file SHA256SUMS.txt contiene l'impronta del pacchetto.
